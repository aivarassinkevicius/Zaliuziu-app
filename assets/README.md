# Assets Folder

## Logo Setup

Įdėkite savo įmonės logo čia su pavadinimu **`logo.png`**

### Reikalavimai:
- **Formatas:** PNG (rekomenduojama) arba JPG
- **Fonas:** Baltas arba skaidrus
- **Dydis:** Bet koks (automatiškai bus sumažintas iki 100px aukščio)

### Automatinis apdorojimas:
- ✅ Baltas fonas bus automatiškai pašalintas
- ✅ Logo bus pridėtas **viršutiniame kairiame kampe**
- ✅ Dydis: 100px aukštis (proporcija išlaikoma)

### Instrukcijos:
1. Pervadinkite savo logo į `logo.png`
2. Įdėkite šį failą čia (`assets/logo.png`)
3. Logo automatiškai atsiras visuose collage

**Jei logo failo nėra - aplikacija veiks normaliai be logo.**
