PAGRINDINIS TIKSLAS:
Sukurti automatizuotą įrankį, kuris paverčia nuotraukas į profesionalius marketinginius įrašus 
socialiniams tinklams (Instagram, Facebook, Magazine format).

MINIMALIOS FUNKCIJOS
1. NUOTRAUKŲ ĮKĖLIMAS
   - Galimybė įkelti 1-4 nuotraukas
   - Palaikyti JPG/PNG formatus
   - Mobiliai draugiškas įkėlimas

2. AI TEKSTŲ GENERAVIMAS
   - Naudoti OpenAI GPT-4 Vision API
   - Generuoti antraštę (header)
   - Generuoti 4 bullet points (marketing punktai)
   - Automatinis nuotraukų analizavimas

3. KOLIAŽO SUKŪRIMAS
   - Magazine Layout: 2 nuotraukos + tekstas + bullet'ai
   - Instagram format: 1080x1080px
   - Facebook format: 1200x630px
   - Automatinis logo įdėjimas
   - Telefono numerio rodymas

4. ATSISIUNTIMAS
   - Galimybė atsisiųsti sukurtą koliažą
   - PNG formato failas
   - Aukšta kokybė (300 DPI konceptualiai)

PRADINĖS INSTRUKCIJOS AI MODELIUI

PROMPT ŠABLONAS tekstų generavimui:

"Tu esi profesionalus marketingo specialistas Lietuvoje, dirbantis su žaliuzių, 
roletų ir langų dangų verslu.

UŽDUOTIS:
1. Išanalizuok nuotrauką/nuotraukas
2. Sugeneruok VIENĄ trumpą, patrauklią antraštę (max 60 simbolių)
3. Sugeneruok 4 bullet punktus (po 40-60 simbolių kiekvienas)

PAVYZDYS OUTPUT:
Antraštė: Modernios žaliuzės jūsų namų elegancija
• Idealiai derančios prie interjero
• Lengvai valomas audinys
• Tikslus šviesos reguliavimas
• Ilgalaikė kokybės garantija"

TECHNOLOGIJOS:
- Python 3.12
- Streamlit (web framework)
- OpenAI API (tekstų generavimas)
- Pillow (PIL) - nuotraukų apdorojimas
- Supabase - duomenų bazė (optional)
