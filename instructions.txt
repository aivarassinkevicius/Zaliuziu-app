===========================================
ŽALIUZIŲ APP - PRADINIS PROJECT BRIEF
===========================================

📋 PROJEKTO PAVADINIMAS:
Žaliuzių ir roletų turinio kūrėjas socialiniams tinklams

🎯 PAGRINDINIS TIKSLAS:
Sukurti automatizuotą įrankį, kuris paverčia nuotraukas į profesionalius marketinginius įrašus 
socialiniams tinklams (Instagram, Facebook, Magazine format).

===========================================
MINIMALIOS FUNKCIJOS (MVP - Minimum Viable Product)
===========================================

1. NUOTRAUKŲ ĮKĖLIMAS
   - Galimybė įkelti 1-4 nuotraukas
   - Palaikyti JPG/PNG formatus
   - Mobiliai draugiškas įkėlimas

2. AI TEKSTŲ GENERAVIMAS
   - Naudoti OpenAI GPT-4 Vision API
   - Generuoti antraštę (header)
   - Generuoti 4 bullet points (marketing punktai)
   - Automatinis nuotraukų analizavimas

3. KOLIAŽO SUKŪRIMAS
   - Magazine Layout: 2 nuotraukos + tekstas + bullet'ai
   - Instagram format: 1080x1080px
   - Facebook format: 1200x630px
   - Automatinis logo įdėjimas
   - Telefono numerio rodymas

4. ATSISIUNTIMAS
   - Galimybė atsisiųsti sukurtą koliažą
   - PNG formato failas
   - Aukšta kokybė (300 DPI konceptualiai)

===========================================
TECHNINĖS SPECIFIKACIJOS
===========================================

TECHNOLOGIJOS:
- Python 3.12
- Streamlit (web framework)
- OpenAI API (tekstų generavimas)
- Pillow (PIL) - nuotraukų apdorojimas
- Supabase - duomenų bazė (optional)

API RAKTAI REIKALINGI:
- OPENAI_API_KEY - GPT-4 Vision prieigai
- SUPABASE_URL - versijų istorijos saugojimui (optional)
- SUPABASE_KEY - autentifikacijai (optional)

LAYOUTO SPECIFIKACIJOS:

Magazine Layout (1080x1350px):
- Kairė: 2 nuotraukos vertikaliai (3:4 ratio)
- Dešinė: Tekstinė sekcija
  - Antraštė: 36px šriftas, bold
  - Punktyrinė linija atskyrimui
  - 4 bullet'ai su apskritimais
  - Telefonas apačioje
  - Logo apačioje dešinėje

Instagram Square (1080x1080px):
- Nuotraukos grid'e (1x1, 2x1, 2x2 layout)
- Tekstas overlay arba apačioje
- Logo watermark

Facebook Cover (1200x630px):
- Horizontalus layout
- Nuotraukos kairėje arba fone
- Tekstas dešinėje

KAIP PRADĖTI PROJEKTĄ NUO NULIO
===========================================

STEP 1: Environment Setup
```bash
python -m venv venv
venv\Scripts\activate
pip install streamlit openai pillow python-dotenv
```

STEP 2: Sukurti .env failą
```
OPENAI_API_KEY=sk-xxxxxxxxxx
```

STEP 3: Sukurti minimalų app.py
```python
import streamlit as st
from openai import OpenAI
from PIL import Image

st.title("Žaliuzių turinio kūrėjas")
uploaded_files = st.file_uploader("Įkelk nuotraukas", accept_multiple_files=True)

if uploaded_files:
    # Process images
    # Generate text with AI
    # Create collage
    # Display result
```

STEP 4: Paleisti
```bash
streamlit run app.py
```
